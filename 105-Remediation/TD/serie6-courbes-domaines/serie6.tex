\begin{definition*}%[domaine de définition, valeurs interdites]
	Le \emphindex{domaine de définition} d'une fonction $f$, noté $\D_f$, est le domaine de $\R$ le plus grand possible sur lequel définir $f$.
	
	Pour cela, il faut étudier la fonction sur $\R$ et supprimer les \emphindex{valeurs interdites}, c'est-à-dire les antécédents pour lesquels $f$ est mal définie.
	Les propriétés suivantes permettre de trouver ces valeurs interdites :
		\begin{enumerate}
			\item l'expression sous une racine carrée doit toujours être positive ou nulle ;
			\item un dénominateur ne doit jamais être nul ; et
			\item un logarithme ne prend que des valeurs strictement positives.
		\end{enumerate}
\end{definition*}
